# SchoolOS v1

A static, responsive student dashboard built with HTML, CSS, and vanilla JavaScript. No build tools needed.

## GitHub Pages
1. Create a public GitHub repository named `schoolos`.
2. Upload `index.html`, `style.css`, and `app.js` to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
6. Open `https://YOUR-USERNAME.github.io/schoolos/` once GitHub Pages has deployed.

## Important
Data is stored in each browser's localStorage. Polls, menus, and events are not shared across users. The site has no authentication, moderation, or official school data integration. Do not enter sensitive student data.
